GITHUB PAGES:
1. Create/open your GitHub repository.
2. Upload index.html to the repository root (the first/main level, not inside another folder).
3. Commit the changes.
4. In repository Settings > Pages, choose Deploy from a branch, select your main branch and /(root), then Save.
5. Open the GitHub Pages URL after deployment completes.
